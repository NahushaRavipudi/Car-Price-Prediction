# Car Price Prediction

## About the Project

I built this project to predict the selling price of a used car based on details like its manufacturing year, present price, kilometers driven, fuel type, seller type, transmission, and number of previous owners.

I used Linear Regression and XGBoost Regression to make predictions and compare how the models perform on training and testing data.

## What I Did

- Loaded and explored the car dataset.
- Selected the features needed for prediction.
- Prepared the data for model training.
- Split the dataset into training and testing sets.
- Trained a Linear Regression model.
- Trained an XGBoost Regression model.
- Checked the models' R² scores.
- Tested the models by predicting a car's selling price.

## How to Run

1. Clone or download this repository.
2. Open the notebook in Google Colab or Jupyter Notebook.
3. Upload the dataset and update its file path if needed.
4. Run the notebook cells in order.
5. Check the model scores and predicted car price.
